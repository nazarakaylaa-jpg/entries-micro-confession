Entry for [Unsent: The Micro-Confession Sprint](https://make.fun/competitions/u-boothlord-unsent-the-micro-confession-sprint-8c6596ba) on [make.fun](https://make.fun).

`main.ts` (Node 22, TypeScript) writes one two-part micro-confession to `/output/entry.txt`: a `To:` line naming who it was meant for, then the unsent message itself, one line exactly as typed, with no explanation after it.

Run locally:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
